## Why

購物車商品數量調整時，庫存同步機制失效導致兩個問題：(1) 增加/減少商品數量後，商品清單與庫存顯示沒有即時反應；(2) 購物車允許添加超過庫存的數量，造成超賣風險。此變更修復庫存同步邏輯並加入庫存上限檢查。

## What Changes

- **修正庫存同步**: 當購物車數量改變時，立即觸發庫存數量的更新與重新渲染
- **加入庫存上限檢查**: 在增加商品數量前驗證剩餘庫存量，防止超過庫存限制
- **改善 UI 反饋**: 當達到庫存上限時顯示適當的提示訊息
- **修復狀態管理**: 確保購物車狀態與庫存資料正確同步

## Capabilities

### New Capabilities

- `cart-inventory-sync`: 購物車與庫存之間的雙向同步機制，包含數量變更時的即時更新與庫存上限驗證

## Impact

- **Affected Components**: 
  - 購物車頁面商品清單渲染邏輯
  - 庫存管理資料層
  - 購物車狀態管理 (state management)
  - API 呼叫層（若涉及遠端庫存檢查）
